プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-05

対象 / Scope

このポリシーは、所有者が個人で運用する Home Assistant と Google カレンダーの連携に使う OAuth クライアント「nirvash Home Assistant Calendar」に適用されます。

This policy covers the OAuth client "nirvash Home Assistant Calendar", used by its owner to connect a personally run Home Assistant to Google Calendar.

取得する情報 / Data accessed

所有者本人が許可した Google アカウントのカレンダーと予定（タイトル、日時など）を読み取ります。

It reads the calendars and events (such as titles and times) of the Google account that the owner has authorized.

利用目的 / How data is used

予定は、所有者の自宅にある Home Assistant の中だけで、ディスプレイへの表示や音声アシスタントへの回答に使います。

Events are used only inside the owner's home Home Assistant, to show them on a display and to answer the owner's voice assistant.

共有・保存 / Sharing and storage

取得した情報を第三者に販売・共有・送信することはありません。認証トークンと予定データは、所有者の Home Assistant の中にだけ保存されます。

Data is never sold, shared or sent to third parties. Access tokens and event data are stored only in the owner's Home Assistant.

Google API サービスのユーザーデータポリシー / Google API Services User Data Policy

Google API から受け取った情報の利用と転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

削除 / Revoking access

アクセスは Google アカウントのアクセス管理 からいつでも取り消せます。取り消すと Home Assistant は予定を読めなくなります。

Access can be revoked at any time from Google Account permissions, after which Home Assistant can no longer read events.
